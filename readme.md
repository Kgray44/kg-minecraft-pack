# KG Minecraft Modpack

A large modpack focused on automation, exploration, military, ships, trains, space travel, engineering, and much more!

Mods are automatically downloaded and kept up to date using **packwiz**.

---

# Installation (Prism Launcher)

### 1. Install Java 21

Download and install Java Version 21 (DO NOT install Java 17 or Java 25):

[Download Java 21](https://www.oracle.com/java/technologies/downloads/#java21)

---

### 2. Install Prism Launcher

Download and install Prism Launcher:

[Download Prism Launcher](https://prismlauncher.org/download/)

---

### 3. Download the Modpack

Download the latest released Prism instance file found in *Releases*:

[**KG_Modpack_Prism_Instance.zip**](https://github.com/Kgray44/kg-minecraft-pack/releases)


---

### 4. Import the Instance

Open **Prism Launcher**

Click:

*Add Instance*

Then choose:

*Import*

Select from downloads:

*KG_Modpack_Prism_Instance.zip*

Prism will create the instance automatically.

---

### 5. Set the Instance Java

You need to select your Java 21 instance so the launcher can use it.

Right-click the modpack instance in **Prism Launcher**

Click:

*Edit*

Open the **Settings** tab.

Open the **Java** tab.

Check the box:

*Java installation*

Click:

*Detect*

Prism will search your computer for installed Java versions.

Select a **Java 21** installation from the list.

Click **OK**.

*The modpack requires **Java 21** to run.

---

### 6. Launch the Pack

Click **Play**.

The first launch will automatically:

- download all mods

- install dependencies

- configure the pack

This may take a few minutes.

---

# Optional Graphics Mods (IMPORTANT)

Some graphics mods can be heavy on weaker computers.

If your game crashes or runs poorly:

Right click the instance in Prism:

*Edit*

Then click (in the left menu):

*Mods*

You can disable heavy graphics mods like:

- Distant Horizons

- Iris Shader Support

Disabling these will improve performance.

## Shader Guide

This modpack includes several shaderpacks so players can choose the visual style and performance level that works best for their system.

Shaders are **optional** and can be enabled from:

*Options → Video Settings → Shaders*

Below are some recommended choices.

### Best Performance

**BSL Shaders**

Recommended for players with weaker GPUs or laptops.

- Good balance of visuals and performance  

- Stable with most mods  

- Works well with **Distant Horizons**

A great **default shader** for most systems.

### Best Visual Quality

**Kappa Shaders**

One of the most visually impressive shaders included in the pack.

- Extremely realistic lighting  

- Beautiful atmospheric effects  

- Very demanding on GPU  

⚠️ **Not compatible with Distant Horizons**

Recommended only for **high-end PCs**.

### Best Visual Quality (Distant Horizons Compatible)

**Bliss Shaders**

A great alternative to Kappa when using **Distant Horizons**.

- Excellent lighting and atmosphere  

- Compatible with **Distant Horizons**  

- Moderate to high GPU usage

Recommended for players who want **high visual quality with distant terrain rendering**.

### Other Included Shaders

Additional shaderpacks included for experimentation:

- Complementary  

- Photon  

- Chocapic  

- KUDA  

- projectLUMA  

- Solas  

- SEUS  

Players are encouraged to try different shaders to find their preferred balance between **performance and visuals**.

### Quick Comparison

| Shader     | Visual Quality | Performance | Distant Horizons |
|------------|----------------|---------------|-----|
| **BSL**    | ⭐⭐⭐        | ⭐⭐⭐⭐    | ✅ |
| **Bliss**  | ⭐⭐⭐⭐     | ⭐⭐         | ✅ |
| **Kappa**  | ⭐⭐⭐⭐⭐   | ⭐           | ❌ |

**Recommended default shader:** BSL (best balance of visuals and performance).

# Updating the Pack

Updates are automatic.

Every time the game launches:

- packwiz checks for updates

- new mods download automatically

No manual updates required.

---

# Recommended Settings

For best performance:

- Prism Allocated RAM: 5 GB minimum

- Prism Allocated RAM: 8-10 GB recommended

- Java: Version 21

*(Will not run with 8GB computer ram total)

These can be adjusted in:

*Prism Launcher → Edit Instance → Settings*

---

# Troubleshooting

### Game crashes on startup

Disable heavy graphics mods:

*Edit Instance → Mods*

Turn off:

- Distant Horizons
- Iris Shaders

---

### Mods won't download

Check your internet connection and relaunch the game.

The installer will retry automatically.
